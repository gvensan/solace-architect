# Skill Improvement Tracking

When feedback reveals a pattern (same issue across multiple projects), it becomes a skill improvement item. This file maps feedback patterns to skill template changes.

Format:
```
## <Skill name>

- [ ] <Improvement description>
  - Pattern: <What feedback revealed>
  - Impact: <What changes for the user>
  - Template: <Which .tmpl file to change>
```
